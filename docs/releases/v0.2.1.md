# Soro-Boro v0.2.1: Router API, CLI, server, and honest numbers

*Draft release notes. No tag or GitHub release has been created.*

**Same weights, much easier to use.**

```python
from soro_boro import Router
router = Router.from_pretrained("nisaralll/soro-kev-0.8b")   # CPU is fine
d = router.route("what's the weather in Paris?", my_openai_or_mcp_tools)
d.action, d.tool, d.repair_args(proposed_args)
```

## Highlights
- `Router` accepts OpenAI, MCP, Anthropic, LangChain, LlamaIndex or plain-function tools and returns
  `EXECUTE` / `ASK` / `ABSTAIN` with calibrated scores.
- `soro-boro route | eval | serve | doctor`, plus an OpenAI-compatible `POST /v1/route` that returns
  `tool_choice`.
- Runnable examples: an OpenAI pre-router, an MCP gateway and framework adapters.
- CI on Python 3.10–3.13 plus a real-weights CPU smoke test.

## Honest numbers
The README now reports confidence intervals over the 115 distinct queries. It also documents the τ²
weakness (10.5% / 24.8%), the 0.8B refusal regression (17/33), and the fact that the "human" split
duplicates the held-out split. `docs/RETRAIN_ANALYSIS.md` explains why no retraining was needed for this
release, and what v0.3 data would fix.

## Upgrading
`pip install -U soro-boro`. `SoroHarness.route(candidates=...)` still works but warns; switch to `Router`.
